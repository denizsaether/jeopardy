
# Jeopardy

Et Jeopardy-spill laget med React, TypeScript og Vite.

## Kom i gang

### Krav
- [Node.js](https://nodejs.org/) installert

### Installer og kjør lokalt

1. Klon repoet:
```bash
   git clone https://github.com/denizsaether/jeopardy.git
   cd jeopardy
```

2. Installer avhengigheter:
```bash
   npm install
```

3. Start utviklingsserveren:
```bash
   npm run dev
```

4. Åpne [http://localhost:5173](http://localhost:5173) i nettleseren.

## Tilpass spørsmål

Alle spørsmål og kategorier redigeres i filen: src/data/mockGame.ts
Her kan du endre kategorier, spørsmål, svar og poengverdier.
